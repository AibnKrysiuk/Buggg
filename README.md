## BUG (Galeria Interactiva de Arte y Poesía).

Este proyecto es una plataforma web interactiva diseñada para [Felix](https://linktr.ee/fffelix), 
donde se exhiben ilustraciones digitales en formato de cartas visuales y una colección de poesía original. 
El objetivo principal fue crear un espacio digital único que refleje la estética y el mensaje del artista, ofreciendo una experiencia inmersiva a los visitantes.

## Características Principales

* Exhibición de Poesía: Sección dedicada a textos poéticos, integrados visualmente con las obras.
* Diseño Responsivo: Adaptable a diferentes tamaños de pantalla (escritorio, tablet, móvil).
* Experiencia de Usuario Intuitiva: Interfaz sencilla que permite enfocarse en el contenido artístico.
* Funcionalidad de Audio.

## Tecnologías Utilizadas

* Frontend: HTML5, CSS3, JavaScript (Vanilla JS).
* Despliegue: Netlify.
